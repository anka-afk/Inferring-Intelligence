# 01 · DPO 录课提纲

对应手稿：[DPO：从偏好数据到策略优化](../../manuscripts/01-dpo/README.md)

状态：提纲初稿，尚未录制。视频与课件发布后在此补充链接。

## 课程目标

让观众能回答：DPO 为什么可以绕开显式奖励模型和 PPO，直接从偏好数据训练语言模型？

先修知识：条件概率、最大似然、KL 散度、梯度下降；了解自回归语言模型的概率分解。

## 建议讲述顺序

以下时长用于备课规划，并非已发布视频的时间戳。

| 环节 | 建议时长 | 讲述与板书重点 |
| --- | --- | --- |
| 开场问题 | 2 分钟 | 手里只有“更喜欢哪条回答”，最终却想训练生成策略 |
| 两条训练路线 | 3 分钟 | 偏好 → 奖励模型 → PPO；偏好 → 策略参数化的似然 |
| 先看损失的含义 | 5 分钟 | 两层相对关系；用正例概率下降的数值例子打破直觉 |
| 推导最优策略 | 7 分钟 | KL 正则目标、归一化约束、拉格朗日乘数、配分函数 |
| 消掉配分函数 | 5 分钟 | BT 只看同一问题下的奖励差；输入相关常数相消 |
| 训练如何计算 | 4 分钟 | 四个序列 log probability、回答 token 求和、冻结参考模型 |
| 梯度与边界 | 4 分钟 | 样本权重、初始化、有限数据与参数化限制 |

## 板书主线

1. 写下偏好三元组 `(x, y_w, y_l)`，明确“偏好标签不等于绝对奖励”。
2. 并列写出当前模型与参考模型的对数概率比，圈出“两层相对”。
3. 推出最优策略与奖励的关系；在两条回答的奖励相减时，划掉相同的归一化项。
4. 代入 sigmoid，得到 DPO 损失；最后回到训练所需的四个序列对数概率。
